# BSG CBT Examination Portal

Independent frontend prototype for the Bharat Scouts & Guides examination portal.

## GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for GitHub Pages to publish the site.

## Important
This is a frontend prototype. Login is demonstrative only; no credentials are authenticated and no answers or marks are stored. Do not use for real examinations until secure authentication, database persistence, examiner marking, result publication, and OYMS integration are implemented and tested.
